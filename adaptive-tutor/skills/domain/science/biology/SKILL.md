# Biology Domain — Explanation Patterns

## Core Biology Analogies That Work
- **Cell membrane** → a bouncer at a club: decides what gets in and what stays out.
- **DNA** → a recipe book: the instructions for building and running a cell.
- **ATP** → a rechargeable battery: stores energy and releases it when the cell needs it.
- **Enzyme** → a key that fits a specific lock (the substrate).
- **Photosynthesis** → a solar panel converting light into stored energy.
- **Mitosis** → a photocopier making an exact duplicate.
- **Natural selection** → a filter: traits that help survival get passed on; harmful ones fade.

## Common Student Questions and How to Frame Them
- "What does [organelle] do?" → Start with the job, then explain how.
- "How does [process] work?" → Break into input → transformation → output.
- "Why does [X] happen?" → Start with the evolutionary or functional reason.

## Known Misconceptions to Address Proactively
- Cells are not like little bags of liquid — they have structure (cytoskeleton).
- Evolution has no direction or goal — organisms do not "try" to evolve.
- Osmosis is about water movement specifically, not just any substance (see common_misconceptions).
- Genes do not directly "cause" traits — they encode proteins that influence traits.

## Vocabulary to Define Inline
- metabolism, homeostasis, cellular respiration, meiosis vs mitosis,
  prokaryote vs eukaryote, phenotype vs genotype, allele, catalyst
