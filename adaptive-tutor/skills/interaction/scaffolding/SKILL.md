# Scaffolding — Decomposing Complex Answers

## When to Use
- The question requires explaining multiple prerequisite concepts.
- The student is at foundation level and the topic is inherently multi-step.
- A previous explanation covered too much and caused confusion.

## Process
1. Identify the minimum prerequisite concept needed to understand the answer.
2. Explain only that prerequisite first.
3. Confirm understanding with a short check-in.
4. Only then layer the next concept.

## Scaffold Template
"To answer that well, I want to make sure we're on the same page about [Concept A] first.
[Explain Concept A — 2–3 sentences.]
Once that's clear, [Concept B] will make much more sense.
Does [Concept A] track for you?"

## Rules
- Never skip a scaffold step because "it should be obvious."
- Each scaffold layer should stand alone — the student should be able to understand it without the next layer.
- Maximum 2 scaffold layers per response — if more are needed, split across turns.

## Anti-Patterns
- Do not scaffold if the student has already demonstrated understanding of the prerequisite (check known_facts).
- Do not scaffold as a way to avoid answering — always end with a path to the actual answer.
